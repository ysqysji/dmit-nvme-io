# DMIT NVMe：全系 NVMe SSD 的公开 I/O 数据、套餐价格与洛杉矶/香港/东京线路怎么选

搜「DMIT NVMe」的人，问题其实很窄：这家卖得不算便宜的 VPS，盘到底是不是真 NVMe，快不快，值不值这个价。剩下的才是买哪台。

先把两件事摆清楚：DMIT 全线是 NVMe SSD 没错，但拿 NVMe 当卖点其实说明不了太多——真正让它贵的是线路。下面把公开测评里的磁盘数据、当前在售的套餐、以及三条线路的差别逐个过一遍。

## 先回答存储这件事

DMIT 的商品页在存储一栏写的是「SSD Storage」或「20G SSD Storage」这类表述，并不会在标题里大喊 NVMe。把它写成「企业级 NVMe SSD」的，主要是第三方测评和中文圈的商家介绍资料。多个来源的口径一致：全系 AMD EPYC 处理器 + 企业级 NVMe SSD + KVM 虚拟化。

几个有记录的时间点：

- 早期平台用的是第二代或更新的 AMD EPYC，配 DDR4 内存。
- 2024 年 10 月，洛杉矶产品线做过一次免费硬件升级，宿主机换成第四代 AMD EPYC 9654，机主不用补差价。
- 现在产品按平台分三代：AS3 用 EPYC 7003（Milan），AN4 用 EPYC 9004 系列（9654 属于这一代），AN5 用最新的 EPYC 9005。三代都是 NVMe 盘。

KVM 这一层值得单独说一句。它的意思是 CPU、内存是你独享的，不会因为同一台物理机上的邻居跑满负载而被抢资源。这不是什么高端能力，但确实有一批低价商家做不到。

## 公开测评跑出来的 I/O 数字

不同测评用的脚本不一样，有 yabs 的 fio 混合读写，也有单片 1M 顺序测试，所以数字之间不能直接横着比。把它当区间看更有意义：

| 机型 | 测试方式 | 关键结果 |
| --- | --- | --- |
| LAX.AN4.Pro.MALIBU（1核/1G/20G） | yabs fio 混合读写 | 4K 读 62.55 MB/s（15.6k IOPS）、写 62.66 MB/s；64K 约 1.06 GB/s；512K 与 1M 均在 1.0–1.07 GB/s |
| LAX.AN4.T1（1核/1G/20G） | yabs fio 混合读写 | 4K 读 41.23 MB/s（10.3k IOPS）；64K 约 521 MB/s；512K / 1M 约 490–523 MB/s |
| TYO.AS3.Pro.TINY | fio 1M 单队列顺序 | 读 340 MB/s，写 1051 MB/s |
| LAX.AN5.Pro.TINY | 综合 I/O | 平均 839 MB/s，4K 写约 114 MB/s / 29.3k IOPS |

怎么读这张表：4K 小块的数字才反映日常建站和数据库的真实体验，六十多 MB/s、一万五千左右的 IOPS，属于「对这价位够用」的水平，不是缩水盘。64K 往上跑到 1 GB/s 以上，说明大文件读写已经吃到 NVMe 的红利。至于同一台机器为什么 4K 和大块差二十倍，这是块大小本身决定的，跟商家没关系。

有测评专门提了一句「I/O 均速 839 MB/s 印证 NVMe 是真实配置」。这个判断逻辑是成立的。也有测评顺手比了别家主打高性能的商家，结论是 DMIT 的盘不是第一梯队——这话也合理，DMIT 卖的本来就不是极致磁盘性能。

## 盘快不快，未必是你的瓶颈

这点对选购更实际。如果你的用途是机场节点、代理、流媒体解锁，那盘的速度对你几乎没影响，线路的延迟和丢包才是全部。只有几类需求会真的被盘拖住：自建站点（尤其 WordPress 这类大量小文件读写的动态站）、数据库、容器镜像和编译、频繁备份解包。

线路这块，公开数据是这样的：

- **洛杉矶 Premium（Pro）**：北京、上海、广州三网回程统一走 CN2 GIA，测评记录到 158ms 延迟、丢包接近 0。香港节点到大陆通常在 20–50ms。
- **洛杉矶 Tier 1**：国际直连，不做大陆优化，同环境延迟约 208ms，丢包约 1%。差 50ms 和 1% 丢包，对实时应用是能感知的。
- **东京 Pro**：三网回程先经 AS23764 CTGNet 进 AS4809 CN2 骨干，再落各地运营商，属于标准的日本 CN2 GIA 路由。
- **Eyeball（EB）**：电信去程 9929 / 58807 负载，联通走 9929，移动走 CMIN2，回程各自走自家精品线路。移动用户在这条线上体验最好，同价位流量也比 Pro 多一截。

换句话说，DMIT 的定价逻辑是：硬件是标配，钱花在线路上。你要判断的是自己更缺哪一样。

## 当前在售的三代平台与三条线路

平台和线路是两个独立维度，别混着看。

平台的现实情况是库存说了算：AN4 一段时间前就被标注接近下架，AN5 重新上架后也很快售罄，目前洛杉矶补货最稳定的是 AS3。有测评拿 Geekbench 5 做过对比，AS3（EPYC 7003）单核约 1000 分，AN5（EPYC 9005）约 1900 分，接近一倍差距；但同样配置 AN5 贵出三成左右。建站、代理、Docker 这类负载，AS3 完全够用；只有在编译、数据库、多线程应用上，AN5 的优势才真正换得回来。

线路分三条：Pro（Premium）、EB（Eyeball）、T1（Tier 1）。它们共用一个挺关键的设计——流量跑完不关机，只降速。Pro 和 EB 的 TINY / Pocket 降到 4Mbps，MINI / MICRO 降到 8Mbps，更大的套餐降到 10Mbps；T1 降速额度高得多，从 100Mbps 到 500Mbps 不等。对做站的人来说，这比直接停机友好太多。

## 常见问题

**DMIT 的盘是 NVMe 吗？**
是。第三方测评跑出的 fio 数据（大块读写稳定在 1 GB/s 上下、平均 I/O 839 MB/s）也支持这个结论。官网商品页不强调这点，但这跟实际配置无关。

**NVMe 和普通 SATA SSD 差在哪？**
主要是随机读写和并发下的响应。NVMe 走 PCIe 直连，队列深度大得多，大量小文件读写时不容易出现明显的 I/O 阻塞。对建站、数据库这类场景，体感差异比跑分看起来更大。

**月付还是年付？**
优惠码基本都要求季付以上，年付单价更低，但 DMIT 库存和产品线变动频繁（东京 EB、香港 EBv2 的下线就是例子）。预算能承受的话，先用月付或季付跑一两个月再说。

**AS3 和 AN5 的差价值不值？**
看你跑什么。CPU 单核性能差接近一倍，但日常建站、代理、Docker 几乎感受不到。编译、数据库、多线程应用才值得加钱。AS3 的价格优势和现货稳定性，对多数人是更实际的选择。

**会不会超售？**
DMIT 一直把不超售作为卖点，KVM 架构也保证了内存和 CPU 独享。第三方测评里流量超额后的实际速度也大致符合官方承诺的降速档位。

**电信、联通、移动该怎么选？**
电信用户、以及对稳定性最敏感的建站业务，选 Pro（三网回程 CN2 GIA）。联通和移动用户优先看 EB，同价位流量更多，移动走 CMIN2 的体验甚至更好。只做海外业务或中转落地，T1 是价格最低的一档。
